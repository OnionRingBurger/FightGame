# ゲーム概要

 - 間合いをコンセプトとした3Dアクションバトルゲーム
 - まずチュートリアルと1ステージを作り切るのが目標、タイトル→セレクト→ステージ→リザルト→タイトルがゲームループとして想定

 - 構成要素はプレイヤー、敵、壁、ゴールorボス(必要に応じて回復アイテムも)



## プレイヤー

 - HPは一般的なゲージ制

 - プレイヤーは近距離攻撃、遠距離攻撃の二種類を使える。
   攻撃はジャンプ攻撃、(タメ攻撃も検討)としても使用可能である。
 - また、敵の攻撃に対し適切なアクションを行うことで威力や攻撃範囲やを強化することができる。
 - 近距離攻撃は隙が少ないが範囲が狭い。殴り合いはもちろん遠距離攻撃が得意な敵に対し距離を詰めることで有効に使用可能。後述するジャンプアクションによる強化幅が大きい。
 - 遠距離攻撃は後隙が多いが範囲や射程が長い。上手く敵と距離を取れば一方的に攻撃できる。後述するガードアクションによる強化幅が大きい

 - ジャンプアクションは敵の攻撃を上空に回避するアクションである近距離の攻撃をタイミング避け、反撃を狙うことができるが、ガードと比べタイミングがシビアでミスした場合直接ダメージを受けてしまう。アクションを決めることで攻撃範囲(扇の広さがメイン)を広げ、次の攻撃に距離の近さに応じたダメージボーナスを乗せる(重ね掛け可能だが、毎回攻撃を与えた方がダメージ効率は良い)。ドンドン攻撃を避けながら近距離攻撃を行うのがメインの運用想定

 - ガードアクションは敵の攻撃を防ぐアクションである攻撃を防ぎながら移動を狙えるが、ダメージを防ぎきることが出来ず、徐々に疲弊していってしまう。アクションを決めることで攻撃範囲(扇の距離がメイン)を広げ、距離に関係なくダメージボーナスを乗せる(重ね掛け可能で何度も載せたほうが強い)。強化攻撃は吸収が可能であり、体力管理のためにも使える。ガンガン耐え、一気に高火力攻撃を返すのがメインの運用想定



## 敵


 - 敵の攻撃範囲は最初透明で、攻撃開始に近づくにつれ、一気に色が付き見えるようになる(ただ覚えるだけでなく、ゲーム内情報だけでもある程度戦えるようにするため)


## 戦闘・アクション

 - ガード、ジャンプアクションは攻撃が当たる位置だけでなく、攻撃がギリギリ当たらない所でも発動する。そのため、敵の攻撃範囲とタイミングを見切る事でリスクを負わずに自身の攻撃を強化できる。つまり敵の間合いを見切り、有効な間合いを上手く維持することで一方的に圧勝できる。一方で攻撃範囲を見切れず、相手の攻撃タイミングを把握しきれなかった場合は失敗してしまう。
 - 構造としてみた時、敵の攻撃という問題に対し、体力などを加味し有効な対抗手段を選択するという工夫、敵や自分のタイミングを覚えるという学習、その学習をもう一歩深めた間合い管理の判断(今は方法が決まっていないが、対抗アクションを使い間合い管理を測れるようにしたいかも)により、どこまでリスクを取り、どのようにリターンを狙うのかを考えることを軸にゲームを構成していきたい。

## メモ

 - ジャンプアクションを決める事で一定時間被弾時のダメージを減らすことも可能にしてもいいかも
 - HPが減った際、移動速度が増え、間合い管理しやすくなっても面白そう
 - アクションにより間合い変更出来てもいいな
 - あえてアクションへの効果が少ないアクション(近距離攻撃を狙うがガードするなど)ができるようになっても面白そう
 - 攻撃範囲を見切った際、タイミングまで合わせるか、対抗アクションをするかは所説。間合いを見切っている場合のみ攻撃を合わせてもいいかも
 - ガードを決めた際遠距離攻撃が自動発生するのもありかも
 - 普通に敵に攻撃を当てた時のメリットも考えてもいいかも
 - 中距離をどうするか。追加するかは諸説
